So this is just a random renderer I used to render my things, nothing special or fancy

Required: `taichi`, `numpy` and `opencv-python`
```bash
pip install taichi numpy opencv-python
```

Usage:
```
usage: rfv10cv.py [-h] [--scene SCENE]
                  [--export-scene EXPORT_SCENE]
                  [--no-embed-assets]
                  [--mc-schem MC_SCHEM]
                  [--headless] [--video]
                  [--output OUTPUT]
                  [--video-output VIDEO_OUTPUT]
                  [--resolution RESOLUTION]
                  [--video-resolution VIDEO_RESOLUTION]
                  [--samples SAMPLES]
                  [--preview-res PREVIEW_RES]
                  [--live-res LIVE_RES]
                  [--live-max-bounce LIVE_MAX_BOUNCE]
                  [--print-keys]
                  [--camera-data CAMERA_DATA]
                  [--camera-multiplier CAMERA_MULTIPLIER]
                  [--camera-offset CAMERA_OFFSET]
                  [--camera-sync]
                  [--camera-get-fps]
                  [--camera-stream CAMERA_STREAM]
                  [--camera-stream-smoothing CAMERA_STREAM_SMOOTHING]
                  [--handheld-shake HANDHELD_SHAKE]
```
